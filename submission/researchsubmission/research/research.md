| **Git Squash**        | بيجمع كذا **Commit** عملتهم أثناء شغلك على Feature في **Commit واحدة**، مع الحفاظ على كل التغييرات، وده بيخلي الـ **History** أنضف ومرتب أكتر بدل ما يبقى مليان Commits صغيرة ملهاش لازمة.                                      |
| **Git Merge**         | بيجمع **Branch** مع Branch تاني، وبيخلي التغييرات اللي في الاتنين موجودة مع بعض، مع الحفاظ على شكل الـ **History** بتاع الفرعين، وغالبًا بيعمل **Merge Commit** عشان يوضح إن الفرعين اتجمعوا.                                   |
| **Git Rebase**        | بياخد الـ **Commits** اللي أنا عاملها في الـ Branch بتاعي ويحطها فوق آخر تحديثات الـ Branch التاني، وده بيخلّي الـ **History** شكله أنضف وخطي بدل ما يبقى فيه تفرعات كتير، بس خلي بالك إنه بيغيّر الـ History بتاع الـ Commits. |
| **Git Help**          | لو نسيت Command أو مش عارف الـ Options بتاعتها، بتستخدمه عشان Git نفسه يشرحلك الأمر وطريقة استخدامه بدل ما تفضل حافظ كل حاجة.                                                                                                   |
| **Git Cherry-pick**   | لو عندي Feature لسه مش جاهزة، لكن فيها **Commit معينة** فيها تعديل مهم وأنا محتاج التعديل ده في Branch تاني، بقدر أختار الـ Commit دي وآخد التغييرات اللي فيها بس، من غير ما آخد الـ Feature كلها.                          |
| **Git Clean**         | لو عندي ملفات في المشروع **Git مش بيتابعها (Untracked)** ومش محتاجها، بستخدمه عشان أنضفها وأشيلها من الـ Working Directory، بس لازم أخد بالي لأنه ممكن يحذفها نهائيًا.                                                          |
| **Git Grep**          | لو المشروع كبير وعايز أدور على كلمة أو اسم Function أو أي Text معين، بدل ما أفضل أفتح الملفات واحد واحد، بستخدمه عشان Git يدورلي عليها داخل الـ Repository.                                                                     |
| **Git Blame**         | لو لقيت سطر في الكود ومش فاهم مين اللي غيره أو التعديل ده اتعمل إمتى، بستخدمه عشان أعرف **مين غيّر السطر ده، وفي أنهي Commit، وإمتى**.                                                                                          |
| **Git Bisect**        | لو عندي Bug ومش عارف ظهر في أنهي Commit، Git بيساعدني أدور عليه بطريقة **Binary Search** بدل ما أراجع الـ Commits واحدة واحدة، لحد ما يحددلي الـ Commit اللي دخلت المشكلة.                                                      |
| **Git Shortlog**      | بيعمللي ملخص للـ **Commit History**، وبيجمع الـ Commits حسب الـ Developer اللي عملها، فمثلًا أقدر أعرف كل واحد عمل كام Commit في المشروع.                                                                                       |
| **Git Prune**         | بيشيل الـ **Git Objects** القديمة اللي مبقاش فيه حاجة بتوصلها ومبقاش ليها استخدام، يعني يعتبر جزء من تنظيف الـ Repository من الحاجات اللي مبقاش ليها لازمة.                                                                     |
| **Git Worktree**      | بيسمحلي أشتغل على **أكتر من Branch في نفس الوقت**، كل Branch في Folder لوحده، فمثلًا أكون شغال على Feature وفجأة محتاج أصلح Bug في Branch تاني من غير ما أوقف شغلي الحالي.                                                      |
| **Git Verify-commit** | بيخليني أتأكد إن الـ **Commit متوقعة بشكل صحيح** وإن الـ Signature بتاعتها صحيحة، وده مفيد لما نكون معتمدين على Commit Signing وعايزين نتأكد من مصدر الـ Commit.                                                                |
| **Git Filter-repo**   | ده بقى من الأوامر التقيلة شوية 😂، بستخدمه لما أكون محتاج **أغير أو أنضف الـ History القديم**، زي إني أشيل ملف أو Secret من كل الـ Commits القديمة، بس لازم أخد بالي لأنه بيعيد كتابة الـ History وبيغير الـ Commit Hashes.     |
